# 安装与运维

[English](usage.md) · **简体中文**

本指南说明 OAuth for ZBoard 的安装与运行。提供方参数见配置参考。

## 安装要求

选择与宿主应用、宿主 API 版本、操作系统和 CPU 架构匹配的包。`admin` 等页面声明表示界面出现的位置；宿主操作权限由能力和宿主策略另行判断。

使用支持导入预览和插件独立信任的 ZBoard 构建。宿主验证签名并保存确认的密钥，无需编辑配置文件。本地构建见[开发指南](development.zh-CN.md)。旧宿主仍需配置 `plugins.trusted_publishers` 并重启。

## 安装插件包

1. 打开插件管理，选择离线导入。
2. 选择签名 `.zbplugin` 文件并查看预览，检查名称、发布者、所需能力和兼容性。
3. 首次遇到未知发布者时，确认来源和签名密钥指纹。信任仅用于此插件。确认导入后，新安装保持停用。
4. 打开插件配置页，保存参数并运行配置检测。
5. 启用插件，使用真实提供方账户完成一次登录验证。

原始 v0.0.1 Release 包未附带公钥。在新版宿主中，展开导入弹窗的兼容选项，填入发行元数据中的发布者公钥即可，无需改配置或重启。使用新版宿主打包工具生成的包自动附带公钥；这些新包需要宿主支持 `signature.json.public_key` 可选字段。

安装、配置、启用和停用均为动态操作，无需重启宿主。配置检测可能只校验参数或提供方元数据；认证插件还需要用真实账户验证完整登录流程。

### 在线安装

配置签名目录后，管理员可从宿主市场页面选择插件。`plugins.catalog_url` 应指向目录文档，受信市场签署的目录可认证选定插件的发布者公钥，安装者无需逐个复制公钥。宿主仍验证包签名、摘要和身份。源码登记文件本身不是签名安装目录。公共分发进度见[项目 README](../README.zh-CN.md)。

## 升级与恢复

升级前，一并备份宿主数据库、插件目录和加密密钥。导入同一插件的新版本会触发宿主升级流程，发布者和签名密钥必须与已有安装一致，卸载后也保留这一约束。换钥需要独立审核的宿主流程，不能静默替换。

ZBoard 在提交变更前准备候选配置、私有数据和运行时。升级成功后保留原启停状态；准备失败则保留旧版本和已提交数据。新包未声明测试过当前宿主版本时，需要先停用插件再升级。

恢复保留版本时，先停用插件，再在详情页选择目标版本。宿主会检查配置与数据兼容性，恢复旧二进制不会执行向下数据迁移。

## 停用、卸载与数据清理

| 操作 | ZBoard 中的结果 |
| --- | --- |
| 停用 | 停止运行时并撤销插件页面与调用会话，保留安装和数据。 |
| 卸载 | 停止插件并移除程序与页面，保留配置、私有数据和操作记录。 |
| 清除保留数据 | 卸载后可用，由宿主清除插件配置与私有数据。 |

账户、身份绑定、订单和凭证等核心记录由 ZBoard 管理。移除插件不会删除这些记录，也不会撤销已完成的业务事务。

## 问题排查

| 现象 | 检查内容 |
| --- | --- |
| 市场为空 | 是否已配置目录，以及目录是否可访问、签名有效且未过期。 |
| 导入被拒绝 | 发布者信任、包摘要、宿主/API 兼容性和目标平台。 |
| 插件启动失败 | 插件操作记录、宿主日志、配置和平台执行策略。 |
| 配置无法保存 | 遇到版本冲突后刷新，再重新应用预期修改。 |

OAuth 相关问题见[配置参考](configuration.zh-CN.md)。[报告问题](../CONTRIBUTING.zh-CN.md)时请提供插件与宿主版本，以及脱敏日志。
